Network Ports: Beginner Study

Objective

To understand common network ports, their associated services, and basic security considerations.

Port 22 — SSH

- Service: Secure Shell
- Purpose: Secure remote administration
- Security measure: Use strong authentication and restrict access.

Port 53 — DNS

- Service: Domain Name System
- Purpose: Resolves domain names to IP addresses.
- Security measure: Use secure configurations and monitor suspicious DNS activity.

Port 80 — HTTP

- Service: Hypertext Transfer Protocol
- Purpose: Transfers web content without encryption by HTTP itself.
- Security measure: Use HTTPS to protect web communications.

Port 443 — HTTPS

- Service: HTTP over TLS
- Purpose: Protects web communications through encryption.
- Security measure: Maintain valid TLS configurations and keep web applications updated.

Key Finding

An open port is not automatically a security vulnerability. Risk depends on the service, its configuration, exposure, and security controls.

Practical Work

This document is a theoretical study. No live network scan has been performed.

Conclusion

Understanding common ports helps cybersecurity students identify network services and recognise basic security risks.
